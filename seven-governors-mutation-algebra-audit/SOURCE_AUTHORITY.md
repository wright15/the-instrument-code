# Source Authority

## Authority order

This companion preserves the Seven Governors four-layer authority rule:

1. the canonical universal network snapshot is the identity source;
2. the audit script derives operator applications and proof ledgers;
3. the optional Neo4j algebra projection materializes those derived facts; and
4. downstream renderers or asset systems may consume, but not rewrite, them.

## Frozen inputs

- `source/universal-network-data.json`
- `source/topology-identity-definitions.json`

Their hashes are recorded in `MANIFEST.json` and
`qa/mutation-algebra-validation.json`.

The four framework documents remain in the Seven Governors integrated release.
They are not duplicated here. This package is a focused, self-contained audit
companion whose executable semantics are fully stated in its script, registry,
schema, and ledgers.

## Mutation boundary

Running this audit does not:

- alter a scale's canonical role, tier, or office;
- promote projection gaps into canonical relationships;
- convert relational-office evidence into categorical office identity;
- declare semantic feature effects; or
- assert a global lattice.

Any such change must return to the upstream audit/canonical-release process and
receive a new protocol version.

## Projection-gap policy

`phase-completion-ledger.csv` and `modal-completion-ledger.csv` compare the
complete formal operators with the currently projected canonical relations.
An unprojected formal application is a reproducible mathematical relation, not
an automatic request to rewrite canon.

The optional Neo4j import uses separate relationship types:

- `MODAL_MUTATES_TO`
- `LOCAL_MUTATES_TO`

This keeps the derived algebra inspectable without conflating it with
`MODAL_SUCCESSOR`, `GOVERNS`, `CONSTRUCTS`, or evidentiary contacts.
