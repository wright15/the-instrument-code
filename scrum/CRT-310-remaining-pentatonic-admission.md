# CRT-310 — Remaining pentatonic set-class admission

**Status:** Backlog · **Priority:** Low · **Points:** TBD · **Epic:** Follow-on Court admission
**Depends on:** CRT-309

## Story

As a release maintainer, I want each pentatonic set class outside the bounded
EPIC-003 scope reviewed under explicit harmonic, complement, transition, and
application evidence before any such class can become admitted Court material.

## Scope

This is the non-dangling admission blocker for the 35 set classes that CRT-302
keeps `proposed`. It must not bulk-promote the field. Each future promotion
requires a versioned substrate release, source provenance, deterministic
fixtures, and an explicit decision-ledger entry.
