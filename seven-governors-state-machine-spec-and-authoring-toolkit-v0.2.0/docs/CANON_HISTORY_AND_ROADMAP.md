## How it started

The original framework organized:

- seven Governor functions;
- canonical diatonic modes;
- photonic anchors;
- a semantic process from emission to fixation;
- a distinction between whole-state and altered-degree governance; and
- a Fivefold elemental/quintessential engine.

The documents were written as an integrated conceptual canon before the full
universal heptatonic topology existed.

## What this package adds

Version `0.2.0` adds a companion explanatory and authoring surface, not a new
normative system layer:

- a cross-reference for installed entities, properties, relationships, and the
  creation-packet endpoint;
- candidate natural-phenomenon assignments;
- a candidate Fivefold Court and thermodynamic interpretation;
- a package-local invariant checklist;
- Cypher questions organized by hypothesis;
- safe proposals against a frozen `governors.yaml` baseline; and
- an admission-aware roadmap from the current graph to possible extensions.

Its optional `PhenomenonModel`/`CourtState` projection is not present in the
active topology, mutation, or profile imports. Package validation proves only
internal candidate consistency.

## Important refinements

### Correspondence is not empirical validation

Natural phenomena can be physically well-defined while their Governor
assignment remains authored. Multiple analogical fit does not transform the
assignment into a scientific discovery.

### D-tier signatures are not automatically lattice meets/joins

The D contact patterns are auditable and valid as declared office-authorizing
mechanisms. Stronger lattice language awaits an explicit partial order and
greatest/least bound proofs.

### Court compression is not thermodynamic entropy

The candidate Fivefold path is a bounded operational geometry. Its
thermodynamic language describes proposed production behavior and accounting,
not an active controller or measured physical state.

### The graph does not eliminate the algebra

The graph supplies candidate equations, domains, counterexamples, and
confluence fixtures. Algebra emerges when those observations are typed and
quantified. A path is data; a law is a versioned assertion over a declared
domain.
