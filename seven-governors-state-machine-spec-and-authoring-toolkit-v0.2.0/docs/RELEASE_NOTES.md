# Release Notes

## 0.2.0 - Companion guide / candidate extensions

Status clarification:

- this package is not the normative Seven Governors system specification;
- installed topology, mutation-audit, profile-registry, Neo4j, and server
  artifacts retain authority; and
- package-local schemas, catalogs, validation results, and optional context
  Cypher do not constitute integrated-release admission.

Companion material added:

- entity, role, relationship, and algebra companion reference;
- invariant checklist in prose and package-local YAML;
- explicit compression-coordinate separation;
- candidate Fivefold Court state machine and operational interpretation;
- candidate seven-model natural-phenomena registry;
- candidate namespace-scoped exclusive assignment policy;
- proposed Rayleigh-scattering/Jupiter mapping, not active canon;
- safe proposal-first `governors.yaml` authoring CLI;
- graph/compiler contract guide;
- hypothesis-driven Cypher cookbook;
- canon crosswalk and capability roadmap; and
- byte-preserved copies of the four source documents.

Refined:

- natural-phenomenon assignments are typed as authored descriptive models;
- D-tier contact signatures are not automatically called lattice
  meets/joins;
- Court compression is distinguished from physical and semantic coordinates;
- Neo4j remains a runtime projection, while YAML remains authoring input; and
- unresolved semantic operator effects remain first-class honest state.

Installed-runtime alignment:

- graph examples use `ScaleState.id`, `ScaleFamily.forte`,
  `GovernorOffice.officeIndex`, `CanonicalFeatureProfile`, and
  `CompiledFeatureProfile`;
- relationship references match the topology, mutation, and profile imports;
- the public creation endpoint is documented as `GET` with required `stateId`
  and optional `domain=landforms` only;
- packet documentation uses top-level `intrinsicFingerprint` and all eight
  actual creation-constraint arrays; and
- route-aware direct compilation is distinguished from the route-free HTTP
  endpoint.

Baseline compatibility:

- canonical feature-profile registry `0.1.1`;
- topology schema `4.0.0-universal-heptatonic`; and
- integrated release authority model with 462 rooted heptatonic states.

Fivefold, natural-phenomenon, and Mercury/Virgo-ledger capabilities are not
included in that active compatibility baseline.
