# Source Authority

## Status of this package

This package is a **companion guide / candidate extensions** package. Its prose,
`catalog/`, `schemas/`, `source/`, and optional Neo4j context projection do not
override the installed release. A package-local schema or validation pass
shows that a proposal is internally well formed; it does not admit the
proposal to the active integrated release.

## One-way authority

The expected flow is:

```text
framework sources / audited inputs
        ↓
versioned canonical and derived audit artifacts
        ↓
profile compiler and Neo4j projections
        ↓
server, explorer, renderer, and generated artifacts
```

A Neo4j node can expose a canonical property; it cannot become canonical merely
because it was edited in the database. A renderer can reveal a relationship;
screen position cannot create one.

Likewise, this companion cannot create authority by duplicating a source file
or restating a catalog. Changes return to the owning upstream artifact, receive
a versioned decision, pass that package's validation, and are then rebuilt into
downstream projections.

## Scoped exclusivity

In this companion's **candidate** phenomenon vocabulary,
`exclusive_primary_descriptive_model` means:

- one office is the only primary owner of that model in this version of the
  Seven Governors ontology;
- other offices may have secondary relational evidence only when explicitly
  recorded; and
- the assignment makes no claim that the natural phenomenon occurs only in
  that office, is caused by that office, or proves that office.

Accordingly, the candidate registry proposes Rayleigh scattering for Jupiter
only within its framework namespace. The installed active graph has no
`PhenomenonModel` nodes or `PRIMARY_PHENOMENON` relationships, so this is not an
active runtime assignment. Rayleigh scattering remains an ordinary physical
phenomenon governed by optical conditions in nature.

## Historical sources

The copies in this package's `source/canon/` preserve historical text for
convenience. The installed framework documents in `../../framework/`, their
hashes in `../../provenance/`, and the relevant accepted release artifacts are
the authority. When historical language sounds like empirical proof of an
authored correspondence, retain the claim classes above; this companion may
clarify interpretation but cannot rewrite the source or promote a candidate.
