# Harmonic Orrery Audio Assets

The three files in `/audio/` are self-authored, unpitched percussion loops.
They are deterministic 22,050 Hz mono PCM WAV renders generated by:

```bash
node scripts/generate-orrery-audio-loops.mjs
```

Run the following to verify the checked-in bytes:

```bash
node scripts/generate-orrery-audio-loops.mjs --check
```
