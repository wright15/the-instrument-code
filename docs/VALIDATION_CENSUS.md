# Validation Census

This census is derived from generated receipts, not hand-written. It traces
every reported validation total to an artifact, a declared scope, a
per-validator count, and the runner that emits it. Prose is never an
independent count source.

The sole authoritative current total is the `checksPassed` field of
`qa/integrated-release-validation.json`, regenerated by `npm run validate:release`
(part of `npm run validate`). The current total is **418**.

The validation-prose consistency check
(`scripts/validate-validation-prose-consistency.mjs`, run as
`npm run validate:prose-consistency`) enforces that any validation total stated
in current-facing prose matches this receipt or carries a release qualifier.
Audio-tuning, line-number, and registry-cardinality numbers are exempt and
recorded rather than counted. Its receipt is `qa/validation-prose-consistency.json`.
